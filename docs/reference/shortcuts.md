# Keyboard shortcuts

| Key | Action |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | New / open / save station |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Del` | Delete selection |
| `J` / `L` | Teach MoveJ / MoveL at the current robot position |
| `F5` | Run the active program |
| `F` | Fit all |
| `T` / `R` | Gizmo translate / rotate |
| `M` | Measure |
| `Esc` | Close dialog / clear selection |
| Mouse | Left orbit, right/Shift pan, wheel zoom, click select, Ctrl-click multi-select, double-click target = move robot |
